## Key UX Principles

### 1. Progressive Disclosure
- Each stage reveals only what's needed
- AI coaching appears contextually
- Advanced options hidden until relevant

### 2. User Control at Every Step
- Save draft anytime
- Edit AI suggestions
- Proceed with warnings (if user chooses)
- Go back to previous stages

### 3. Evidence-First Design
- Real quotes from real interviews
- E1 evidence tier (direct) prioritized
- Patterns emerge from user's data

### 4. AI as Coach, Not Generator
- AI asks questions
- AI provides frameworks
- AI suggests, user decides
- AI synthesizes user's inputs

### 5. Clear Progress Tracking
- Visual stage progression
- Scores and readiness indicators
- Recommendations (not requirements)

### 6. Actionable Next Steps
- Interview guides ready to copy
- Experiment templates
- Export options
