Technical Architecture

Architecture Style: Microservices. This architecture provides the necessary isolation and scalability for different aspects of the platform, such as data ingestion, AI model execution, API serving, and user interface components. The microservices architecture allows independent deployment and scaling of individual services based on their specific resource needs, which is critical for handling varying workloads and future feature additions. It also allows different teams to work on different services independently, speeding up development and deployment cycles. Furthermore, it promotes fault isolation, meaning that a failure in one service does not necessarily bring down the entire platform. Given the compliance requirements (APRA, CDR), the modularity of microservices allows for easier auditing and security enforcement at the service level. While more complex to manage initially, the long-term benefits of scalability, maintainability, and resilience outweigh the initial overhead.

The system consists of several microservices communicating through an API Gateway. The Digital Channels (Web and Mobile) interact with the platform via the API Gateway, which handles authentication and routing. The Data Ingestion Service collects data from external sources like Accounting Software (Xero, MYOB, QuickBooks) and Bank APIs (CDR). The Data Storage layer persists the ingested data. The AI Model Service performs cash flow forecasting using machine learning models. The Alerting Service
