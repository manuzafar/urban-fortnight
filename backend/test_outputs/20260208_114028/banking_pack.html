Technical Architecture

Architecture Style: Microservices. This architecture allows for independent scaling, deployment, and fault isolation of different components. It aligns well with the need for integrating with various accounting software and banking APIs, as each integration can be a separate service. It also enables different teams to work on different parts of the system concurrently, reducing time-to-market. While microservices introduce complexity in terms of service discovery and inter-service communication, the benefits of scalability and maintainability outweigh the costs for a platform with multiple integrations and evolving business requirements.

The architecture consists of several microservices, each responsible for a specific function. The API Gateway acts as the entry point for all external requests, routing them to the appropriate service. The Authentication Service handles user authentication and authorization. The Accounting Integration Services are responsible for connecting to Xero, MYOB, and QuickBooks. The Bank Integration Service connects to bank transaction data via Open Banking (CDR).
